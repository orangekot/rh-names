FAQ

Quick answers for .rh name holders. Builders: see Docs.

What is a .rh name?

A human‑readable username on Robinhood Chain (for example alice.rh). It can point to your wallet address and show a primary name in apps that integrate our ENS‑compatible contracts.

Is a name permanent?

No — names are rented. Minimum registration is 28 days. You can renew before expiry. Longer durations get stepped discounts (up to 48% off).

How much does it cost?

Yearly rent (before duration discounts): 0.03 / 0.01 / 0.005 ETH for 3 / 4 / 5+ character labels. Live quotes on the home page and during registration use the on‑chain price oracle.

Why do I commit before register?

Commit‑reveal reduces front‑running. You commit a secret, wait about a minute, then register. Keep the same browser/device until register finishes so your secret is available.

What is a primary name?

The .rh name you choose to represent your wallet address (reverse record). Set it from My names after you own a name. Wallets and explorers that support .rh can then show your name instead of a raw 0x address.

Can I receive transfers to alice.rh?

Yes — once a wallet or app resolves .rh names. They look up the name on Robinhood Chain and send to the address it points to. Until a given wallet adds support, paste your 0x address as usual. Integrator details: Docs.

Which chain do I need?

Robinhood Mainnet, chain ID 4663. Add the network in MetaMask/Brave if needed (RPC https://rpc.mainnet.chain.robinhood.com).

Are names NFTs?

Yes. Ownership is an ERC‑721 on the Base Registrar. The registry + resolver handle name data and resolution.

Is this the same as ENS .eth on Ethereum?

Same family of contracts (registry, registrar, resolver, reverse), but deployed on Robinhood Chain for the .rh TLD. It is not an L1 .eth name and is not automatically visible on Ethereum mainnet ENS apps unless we add cross‑chain bridges later.
