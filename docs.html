Integrate .rh names

Documentation for wallets, explorers, dApps, and indexers that want to resolve Robinhood Chain usernames ending in .rh — similar in spirit to ENS docs, tailored to our live Phase‑1 contracts.

1. Overview

.rh is an ENS‑compatible name system on Robinhood Mainnet (chainId 4663). Names are rented (not permanent), owned as ERC‑721 NFTs on the Base Registrar, and resolve through a standard ENS registry + resolver.

  • Forward: alice.rh → Ethereum address (coin type 60)
  • Reverse / primary: 0x… → preferred alice.rh
  • Text: avatar, url, description, socials (EIP‑634 keys)

End users register at rh.names. This page is for builders integrating the stack.

5. Forward resolution — name → address

Same mental model as ENS:

  1. Normalize label (lowercase, no trailing .rh in registry ops).
  2. node = namehash("label.rh")
  3. resolver = ENS.resolver(node)
  4. addr = resolver.addr(node) (EIP‑137) or multicoin addr(node, 60)

Minimal ABI fragments

// ENSRegistry
function resolver(bytes32 node) view returns (address)

// Resolver
function addr(bytes32 node) view returns (address)
function addr(bytes32 node, uint256 coinType) view returns (bytes)
function text(bytes32 node, string key) view returns (string)
function name(bytes32 node) view returns (string)

cast (CLI)

export RPC=https://rpc.mainnet.chain.robinhood.com
export ENS=0xF3fcF2aeef2b49F33C9882C28b526558C675Df5a

NODE=$(cast namehash alice.rh)
RESOLVER=$(cast call $ENS "resolver(bytes32)(address)" $NODE --rpc-url $RPC)
cast call $RESOLVER "addr(bytes32)(address)" $NODE --rpc-url $RPC

6. Reverse resolution — address → primary name

Users set a primary name so wallets/explorers can show alice.rh instead of a raw 0x… address.

  1. User owns alice.rh and points its resolver addr at their wallet (usually done at register).
  2. User calls ReverseRegistrar setName("alice.rh") from that wallet.
  3. Integrators read reverse: compute reverse node for the address, load its resolver, call name(node).

Set primary (user write)

// ReverseRegistrar
function setName(string name) returns (bytes32)
function node(address addr) pure returns (bytes32)
function defaultResolver() view returns (address)
REVERSE=0xF2Cc3fB65ea90162B0556519022D84CfeD3c323C
# from the user's wallet (signing tx):
cast send $REVERSE "setName(string)" "alice.rh" --rpc-url $RPC

Read primary for an address

// 1) reverse node for address
REV_NODE=$(cast call $REVERSE "node(address)(bytes32)" 0xUser… --rpc-url $RPC)
// 2) resolver on that reverse node (often default resolver)
RES=$(cast call $ENS "resolver(bytes32)(address)" $REV_NODE --rpc-url $RPC)
// 3) EIP-181 name
cast call $RES "name(bytes32)(string)" $REV_NODE --rpc-url $RPC
Wallet send‑to flow: when the user types alice.rh in a transfer field, resolve forward → addr and send to that address. When displaying history, reverse‑resolve the counterparty address for a friendlier primary name (if set).

8. Code snippets

ethers v6

import { ethers } from "ethers";

const RPC = "https://rpc.mainnet.chain.robinhood.com";
const ENS = "0xF3fcF2aeef2b49F33C9882C28b526558C675Df5a";
const provider = new ethers.JsonRpcProvider(RPC, 4663, { staticNetwork: true });

const ens = new ethers.Contract(ENS, [
  "function resolver(bytes32) view returns (address)",
], provider);

const resolverAbi = [
  "function addr(bytes32) view returns (address)",
  "function text(bytes32,string) view returns (string)",
  "function name(bytes32) view returns (string)",
];

export async function resolveRh(name) {
  const full = name.endsWith(".rh") ? name.toLowerCase() : `${name.toLowerCase()}.rh`;
  const node = ethers.namehash(full);
  const resolverAddr = await ens.resolver(node);
  if (resolverAddr === ethers.ZeroAddress) return null;
  const resolver = new ethers.Contract(resolverAddr, resolverAbi, provider);
  const addr = await resolver.addr(node);
  return addr === ethers.ZeroAddress ? null : addr;
}

export async function reverseRh(address) {
  const reverse = new ethers.Contract(
    "0xF2Cc3fB65ea90162B0556519022D84CfeD3c323C",
    ["function node(address) pure returns (bytes32)"],
    provider,
  );
  const revNode = await reverse.node(address);
  const resolverAddr = await ens.resolver(revNode);
  if (resolverAddr === ethers.ZeroAddress) return null;
  const resolver = new ethers.Contract(resolverAddr, resolverAbi, provider);
  const name = await resolver.name(revNode);
  return name || null;
}

viem

import { createPublicClient, http, namehash, getAddress } from "viem";

const client = createPublicClient({
  chain: {
    id: 4663,
    name: "Robinhood",
    nativeCurrency: { name: "ETH", symbol: "ETH", decimals: 18 },
    rpcUrls: { default: { http: ["https://rpc.mainnet.chain.robinhood.com"] } },
  },
  transport: http(),
});

const ensAbi = [{
  name: "resolver", type: "function", stateMutability: "view",
  inputs: [{ name: "node", type: "bytes32" }],
  outputs: [{ type: "address" }],
}];
const addrAbi = [{
  name: "addr", type: "function", stateMutability: "view",
  inputs: [{ name: "node", type: "bytes32" }],
  outputs: [{ type: "address" }],
}];

export async function resolveRh(labelOrName) {
  const full = labelOrName.endsWith(".rh")
    ? labelOrName.toLowerCase()
    : `${labelOrName.toLowerCase()}.rh`;
  const node = namehash(full);
  const resolver = await client.readContract({
    address: "0xF3fcF2aeef2b49F33C9882C28b526558C675Df5a",
    abi: ensAbi,
    functionName: "resolver",
    args: [node],
  });
  if (resolver === "0x0000000000000000000000000000000000000000") return null;
  const addr = await client.readContract({
    address: resolver,
    abi: addrAbi,
    functionName: "addr",
    args: [node],
  });
  return addr === "0x0000000000000000000000000000000000000000"
    ? null
    : getAddress(addr);
}

9. Registration (for full wallet support)

Users can register from the public site. Wallets that want in‑app registration:

  1. controller.available(label) / valid(label)
  2. rentPrice(label, durationSeconds) → pay base + premium
  3. commitment = makeCommitment(label, owner, secret)
  4. commit(commitment) → wait minCommitmentAge (≥ 60s)
  5. register(label, owner, duration, secret, resolver) payable
  6. Optional: ReverseRegistrar setName("label.rh")
ABI note: our slim controller commitment is keccak256(abi.encodePacked(labelhash, owner, secret)) — not the L1 ETHRegistrarController Registration struct. Do not drop in ensjs register helpers without adapting the hash.

Pricing (v3): yearly 0.03 / 0.01 / 0.005 ETH for 3 / 4 / 5+ character labels, plus duration discounts (+4% off per full 30 days past the 28‑day floor, max 48%). Min registration: 28 days.
